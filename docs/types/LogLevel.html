    Defines the LogLevel type, which represents the different levels of logging (verbose, info, warnings, errors) that can be enabled or disabled in the Logger class.

    Each property is a boolean indicating whether that log level is active or not.

        errors: boolean;
        info: boolean;
        verbose: boolean;
        warnings: boolean;
